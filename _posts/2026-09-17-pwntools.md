# 1. Introducción

`Pwntools` es un **framework** de `Python` muy potente que se utiliza sobre todo para la explotación de binarios. Basicámente, nos facilita mucho el trabajo a la hora de hacer exploits y poder comunicarnos con binarios.

También tiene versión para `Ruby` pero veo más util para Python.

Para instalarlo con pip para Python seguiremos lo siguiente:

```sh
pip3 install pwntools
```

CURIOSIDAD: pwntools fue diseñado para operar en sistemas `Linux/Unix` no está disponible para windows ya que usa módulos que no están disponibles para Windows.
