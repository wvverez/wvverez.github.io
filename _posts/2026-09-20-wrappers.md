Cuando trabajamos con archivos PHP, aparece un concepto bastante interesante llamado `PHP Wrappers`.

Un wrapper se puede entender como una especie de “envoltorio” que le indica a PHP cómo debe tratar un recurso o un Stream. Un Stream es, básicamente, una forma de manejar datos, como puede ser la lectura de un archivo, una entrada, una salida o incluso una conexión.

Lo interesante de los PHP Wrappers es que PHP no tiene por qué trabajar únicamente con archivos normales. Dependiendo del wrapper que utilicemos, podemos hacer que PHP trate ese recurso de una forma diferente. Por ejemplo, existen wrappers que permiten trabajar con archivos, datos, URLs o modificar la forma en la que se procesa determinada información.

Esto puede ser especialmente interesante desde el punto de vista de la seguridad y el pentesting, ya que algunas de estas funciones pueden aprovecharse en vulnerabilidades como LFI (Local File Inclusion) o un XXE. En muchas situaciones, utilizar un wrapper nos permite hacer cosas que no podríamos conseguir utilizando una inclusión de archivos tradicional.

Al principio, el concepto de “envoltura” puede parecer un poco raro, pero realmente es muy fácil cuando ves cómo funciona esto.

A continuación, voy a enseñar algunos de los PHP Wrappers más utilizados y cómo podemos aprovecharlos en diferentes situaciones para conseguir ejecución remota de código o inclusión de archivos normal.
