# 1. Introducción

`Pwntools` es un **framework** de `Python` muy potente que se utiliza sobre todo para la explotación de binarios. Basicámente, nos facilita mucho el trabajo a la hora de hacer exploits y poder comunicarnos con binarios.

También tiene versión para `Ruby` pero veo más util para Python.

Para instalarlo con pip para Python seguiremos lo siguiente:

```sh
pip3 install pwntools
```

CURIOSIDAD: pwntools fue diseñado para operar en sistemas `Linux/Unix` no está disponible para windows ya que usa módulos que no están disponibles para Windows.

# 2. Procesos

Un proceso normalmente es la principal forma de interactuar con algo desde `pwntools` y empezar uno es bastante fácil.

```sh
p = process('./binario')
```

También podemos iniciar como procesos **remotos** y conectarte a sockets si usas `remote`.

```sh
p = remote('IP', port)
```

El verdadero potencial de `pwntools` en cuanto a procesos es que es muy simple comunicarte con tus procesos.

## p.send(data)

Mete data para los procesos. Pueden ser `strings` o un `byte-like object`, de eso todo se encarga `pwntools`.

## p.sendline(data)

Envía ddatos a un proceso pero seguido de un salto de línea `\n`. Algunos necesitan que el salto de línea tome esa entrada, es como cuando das ENTER al conectarte con `nc` mientras que otros no lo necesitan.

NOTA: Si metes más saltos de línea de los que deberías puedes hacer que el exploit se pare, y si no puedes usar `p.clean()`.
