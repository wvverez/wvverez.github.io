# 1. Pequeña introducción

El `kernel` es el programa principal de el `SO`. Es el responsable de controlar cualquier aspecto de el ordenador desde las `syscalls` hasta la integración entre **software** y **hardware**. Es por esto por lo que tocar kernel de forma ofensiva puede conllevar a errores muy críticos.

En el contexto de los retos CTF (Capture The Flag), tocar kernel suele conllevar a la explotación de `módulos` del kernel. Esta es una principal carácteristica y es que se permite a los usuarios extender el propio `kernel` con su propio código.

Recomiendo para seguir este post tener una pequeña base en `controladores y módulos` de el kernel.
